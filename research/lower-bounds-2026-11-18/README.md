# 同步多数模型：更强的恢复时间下界

在无限二维整数格点上，每轮所有格点同时读取各自的四个正交邻居并取多数，平票以独立公平随机结果决定。令 `T_N` 为从白底全黑 `N × N` 方形出发，首次恢复全白所需的轮数。若始终没有恢复，则取无穷。这里的 `N` 是边长，按格点个数计；`τ(N)` 是最小包围方形边长恰为 `N` 的有限初态中最坏的期望恢复时间。

**期望下界。** 对所有整数 `N ≥ 1`，`τ(N) ≥ E[T_N] ≥ max(N/2, N²/1,900,000)`。第一步将凸角与凹角的权重差逐行计数，再把各轮的生存概率相加，得到 [全尺度下界 `N²/4,000,000`](lower-bound.md)。第二步用空象限中的三角形区域给出更大的缺失权重，将分母降至 `1,900,000`。线性项来自更新范围：在第 `k` 轮，只要 `2k < N`，格点 `(k,k)` 的初始依赖范围仍完全在黑色方形内，因此每次实验都至少需要 `⌈N/2⌉` 轮恢复。

**过快恢复的概率。** 给定非负整数轮数 `k`，令 `r = ⌊√k⌋+1`，取小方形的边长 `m = 2,000r`。单个小方形至迟第 `k` 轮恢复的概率至多为 `1/2`。当 `r < 1,000` 时，由 `k < r²` 可知 `2k < m`，所以必定还未恢复。当 `r ≥ 1,000` 时，[全尺度下界的式（2）](lower-bound.md) 给出 `P(T_m > k) ≥ 47/50 − 420,000(k+1)/L²`，其中 `L = ⌊(m−1)/2⌋ = 1,000r−1 ≥ 999r`。代入 `k+1 ≤ r²` 后，右端至少为 `47/50 − 420,000/999² > 1/2`。

大方形可容纳 `⌊N/m⌋²` 个互不重叠的小方形。每个小方形单独演化时，外面的格点最多只有一个黑邻居，因而会一直保持白色。这样，每个小方形只需使用各自位置的独立随机标记，恢复事件也独立。在平票结果相同的情况下，增加黑邻居不会让一个格点从更新为黑变成更新为白。因此，大方形至迟第 `k` 轮恢复意味着每个单独演化的小方形到那一轮都已恢复。将这些独立事件的概率相乘，得到

```text
P(T_N ≤ k) ≤ (1/2)^(⌊N/m⌋²)
           ≤ 2 exp(−(log 2) N² / (64,000,000 (k+1))).
```

例如，`k = 9,000,000` 时 `m = 6,002,000`。取 `N = 12,004,000`，可以放下四个小方形，第一式给出 `1/16`。

这两项结果是 [A/B 论文工作稿](../revision-ab-2026-11-17/paper/paper.md) 之后的补充。对应 Lean 入口为 [期望下界](ImprovedMean.lean) 中的 `tau_improved` 和 [过快恢复概率](FastTail.lean) 中的 `finite_lower_tail`、`exponential_fast_tail`。
