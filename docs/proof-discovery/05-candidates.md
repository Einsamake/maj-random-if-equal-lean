# 比较方法的适用条件

本目录涉及的观察量和比较原理均有明确结构条件。以下归纳用于说明本题证明的组成，不主张它们构成新的普遍方法。

| 方法 | 已验证结构 | 结论范围 |
| --- | --- | --- |
| 零权边界 | 被禁止的可能出生集中在 $\|v\|_1=L+2$；权重在该层为零，在域内为正 | 同一支撑状态下两更新算子的加权漂移相等；目标阈值及漂移总界仍须另证 |
| 正部平方能量 | 有限坐标、有限置换、非负源项和非正初值 | 序保持；非双射映射一般不能沿用相同求和消去 |
| 热能量与二阶矩 | 有限路径矩方程、Poincaré 界和异点非正协方差 | 平方时间的局部清空概率；不是粒子独立性结论 |
| 有限状态时钟补偿 | 实际事件 law、可测更新前代表与所需可积性 | 将逐事件增量转为物理时间积分；不是仅由生成元代数自动得到 |
| 扩展尾和与重启 | 保留无穷首达时间，以及对后续状态一致的块失败率 | 有限期望与显式期望上界；一次成功率本身不足以推出 |

[三点有向环](06-first-reuse.md)提供一个与格点无关的有限置换比较实例，以及非双射通量反例。该实例说明所调用定理的适用结构，并不建立任意有向网络的未加权耗散定理。
