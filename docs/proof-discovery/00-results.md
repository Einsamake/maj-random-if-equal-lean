# 这次成果放在哪里

## 一道题，两件不同的事

问题是有限黑色扰动平均多久消失。证明完成以后，我们还想找出它留下了哪些可学、可用的方法。前者已经有正式定理；后者从本目录开始调查。

规则只读上、下、左、右四格，不读自己。三票或四票决定颜色；二比二时，每格每轮独立掷公平硬币。所有格同时更新。全白和全黑都是背景，允许对任一背景作有限扰动。

恢复时间是某条随机演化第一次回到全背景颜色的轮数；永远不恢复的演化记为 ∞。对全白背景，就是第一次所有黑格都消失。

N 是包住扰动的最小格点正方形边长，不是黑格数。边与横纵坐标平行，位置可以平移；例如黑格只在 (0,0) 与 (2,1)，最小方框要有3列、3行，所以 N=3，尽管只有两个黑格。严格定义用半开方形 [a,a+N)×[b,b+N) 避免重复计边。

对一个确定初态先平均硬币造成的恢复时间，再对尺寸恰为 N 的初态取最坏值，得到 τ(N)。单条演化的恢复时间、一个初态的平均时间、最坏初态的平均时间，是三个层次。

最终定理是

\[
N^2/56623104000\leq\tau(N)\leq664066N^2,
\qquad N\geq786432000.
\]

上界单独对 N≥16 成立。显示常数很松，结论是充分大尺寸下的二次同阶；不能用这些常数预测一个小图形的实际寿命，也不能把最坏平均值读成每条轨迹都在相同时间内消失。
