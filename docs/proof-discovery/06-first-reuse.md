# 第一次复用：离开格点以后，引理还能工作吗？

先选一个很小的目标：三个格子的量按循环规则流动，两组系统起初一组不多于另一组，而且外部输入也较小，能否保证以后一直较小？这里“较小”是每一个对应格子都较小。

这不是一个新的现实模型成果。它是对“这个比较引理是否真的脱离本题几何”的小型检验。我们没有先研究带噪网络、控制系统或别的复杂应用，以免用设想代替实际使用。

## 三个格子，两个场

坐标是 i=0,1,2，i+1 按模3计算。给定两组随时间变化的函数 u、v，满足

\[
u_i'=\tfrac12(u_{i+1}-u_i)+f_i,
\qquad
v_i'=\tfrac12(v_{i+1}-v_i)+g_i.
\]

假设它们在非负时间连续，在正时间满足导数方程，且 u_i(0)≤v_i(0)、f_i(t)≤g_i(t)。我们只证明顺序保持，不在这里证明这些流的存在性或外力本身的物理来源。

令 c=u−v，s=g−f，直接相减得到

\[
\begin{aligned}
c_i'&=u_i'-v_i'\\
&=\tfrac12[(u_{i+1}-v_{i+1})-(u_i-v_i)]+f_i-g_i\\
&=\tfrac12(c_{i+1}-c_i)-s_i.
\end{aligned}
\]

循环移位 i↦i+1 mod 3 是真正的有限置换，s≥0、初值 c≤0，所以正好满足第二课的比较原理，得 c≤0，即 u≤v。写出这一行差方程，才说明新对象确实落入旧引理，而不是仅因名字叫“扩散”就调用它。

[ReuseExample.lean](ReuseExample.lean) 的 `three_cell_order` 就是这个实例。它没有使用格点边界、粒子槽位、协方差或随机硬币。这里的循环移位甚至不是两点交换，显示原引理的输入确实是一般置换。

标准 Lean `--trust=0` 对这个新文件的实际结果见 [reuse-validation.json](reuse-validation.json) 和 [原始输出](reuse-kernel.log)。它放在教程目录，不纳入已封存的267份正式源，也不把原主定理的3280条分析辅助定理数改成新的版本。

## 故意破坏一个假设

为什么每个更新动作必须是双射？看两个坐标，令非双射映射同时把0和1送到1，取数值 a=(1,2)。那么

\[
\sum_{i=0}^{1}2\max(a_i,0)(a_{\sigma(i)}-a_i)=2>0.
\]

右端不能再靠置换换元相消，正部平方能量耗散的这条证明就失效。[同文件](ReuseExample.lean) 的 `nonbijective_flux_positive` 以精确算术核查了这个反例。

注意它反驳的是“任意映射都满足这个未加权能量耗散式”，不是反驳一般合作系统的顺序保持。那个更广泛的结论可能用其他方法证明。把证明路线失败误读成定理错误，也是一种应当避免的推断。

## 这次检验得到什么

已得到：一个脱离原格点模型的确定性调用实例，和一个明确限制当前能量证明适用范围的反例。没有重建正部能量的微积分，只证明新方程能落进已有接口。

还没有得到：新的比较定理、新的随机过程结果、真正的现实应用，或相对于现有数学库明显节省工作量的基准。下一步若选择更复杂的系统，必须报告它能否满足当前置换结构，不能只因名字叫“扩散”就套用。
