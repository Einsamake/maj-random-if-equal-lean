# 从一份 AI 证明里，还能学到什么？

我们已经得到一个结果：在无限白色方格纸上放一块有限的黑色图形，让每格同时服从四邻多数、平局独立掷公平硬币，它最终消失所需的最坏平均时间与 N² 同阶。这里 N 是包住初始黑格的最小正方形边长，恢复时间是第一次全白的轮数；先对硬币平均，再对同一尺寸的初态取最坏值。

现在换一个问题：**除了这个答案，证明途中有没有留下值得人类学习、甚至拿去解决别的问题的办法？**

这里从三个有源码支持的转折开始。它是一份可修改的研究教程初稿，不是完整证明的替代品，也不把所有技巧预先命名为创新。

建议先读第一课。它有一个可以亲手数的小例子：一个被禁止的更新会破坏原来的面积计算；换一个权重以后，那个更新的影响恰好为零。

阅读约定：按第一课→第二课→第三课阅读，成果与路线两篇可以按需要查阅。每课说明哪些推导当场展开、哪些已证结果暂作输入。不懂 Lean 不影响阅读正文；源码和验证链接供需要追查的人使用。

本目录里的文字有三种不同身份，章节中会直接说明：源码中的定理；日期记录支持的探索；为了讲清数学而事后重组的解释。教程不声称复原模型内部的思维，也不会替缺失的记录编造发现经过。

目前整理了成果入口、三篇首批教程和五项方法候选，并做了一个独立于格点几何的小型调用实例。尚未逐页讲解整份证明，也没有完成新方法的独立文献定位或第二个实质不同问题的迁移验证。后续从候选中选一个做真正的外部使用，再判断它是否值得单独发表。

[本轮材料核查记录](validation.json)固定了引用的源码、例子和图像。原主定理的内核验收仍引用既有记录，没有重复构建；只有新写的小型复用文件另行运行了标准内核检查，见[专项记录](reuse-validation.json)。

每轮写完另做本科读者模拟测试：让无项目背景的代理只读正文和图，实际复述、算例并指出卡点，再据此修改。首轮反馈见[反馈与改稿](reviews/round-1.md)，最终复读见[读者测试记录](reader-review.json)。这与真实人类测试、专家评审是不同层面的证据。
