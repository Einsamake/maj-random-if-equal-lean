# 随机多数投票：一块黑色图形要多久才会消失？

在无限大的白色方格纸上涂黑一些格子。此后，每个格子根据邻居的颜色，决定自己下一步变黑还是变白。我们研究的问题是：**当初始图形的尺寸 N 足够大时，最坏平均消失时间是否与 N² 同阶？**

**这项二次尺度定理已经完成 Lean 形式化，并通过标准内核的统一检查。** 下文先用一个 3×3 方块解释问题，再说明证明的关键思路。尚未经过独立人类专家评审。

## 格子怎样变色？

每个格子只看上、下、左、右四个邻居。黑色占多数就变黑，白色占多数就变白；两黑两白时，掷公平硬币决定。不同格子、不同轮次的硬币彼此独立。

![四邻投票规则：黑多选黑，白多选白，两黑两白时各有一半机会](docs/images/01-rule.png)

所有格子同时更新，读取的都是上一轮的颜色。中心格自己的旧颜色不参加投票。

下面从同一块 3×3 黑色方块出发，实际模拟了一次演化。

这一次，第 7 步首次变成全白，因此恢复时间是 7。橙框中的格子曾经变白，后来又变黑：图形并不是一层层擦掉的。

## “最坏平均时间”是什么意思？

先固定初始黑色图形 S，把首次全白的步数记作 T(S)。我们关心它对所有硬币结果的平均，也就是期望 E[T(S)]；若始终不恢复，则恢复时间记为无穷。

再比较不同初始图形。这里的尺寸 N 是能包住所有黑格的、沿横竖格线放置的最小正方形边长，单位是格。它不是黑格总数。例如，下图三种图形的尺寸都是 3。

![最坏平均恢复时间的定义示意：三种尺寸为3的图形，其理论平均标作A、B、C，并非测量值](docs/images/05-worst-case.png)

先对硬币结果取平均，再对尺寸恰好为 N 的所有初始图形取最大值，得到

$$
\tau(N)=\max_{S:\,\mathrm{size}(S)=N}\mathbb{E}[T(S)].
$$

“与 N² 同阶”是指存在与 N 无关的正常数 c、C，使所有足够大的 N 都满足

$$
cN^2\leq\tau(N)\leq CN^2.
$$

两边要求不同：下界要找出平均至少要这么久才能恢复的图形；上界要保证所有同尺寸图形的平均恢复时间都不超过这个量级。黑白互换后问题相同，因此也涵盖白色扰动落在全黑背景上的情形。

## 证明得到了什么？

已经证明：对所有足够大的 N，最坏平均恢复时间与 N² 同阶。下界用一整块 N×N 黑色方块作见证；上界覆盖所有尺寸恰为 N 的图形。恢复时间的定义保留“永不恢复”的无穷值；有限期望是证明的结果。

<details>
<summary>看精确常数和适用范围</summary>

对 N≥786432000，完整结论是

$$
\frac{N^2}{56623104000}\leq\tau(N)\leq664066N^2.
$$

上界单独对 N≥16 成立。这些常数为方便严格证明而选取，没有优化；标准的 Θ(N²) 是“所有充分大的 N”的结论，这组显示常数不声称覆盖每个正整数 N。

</details>

## 为什么是平方时间？

下界要证明方块不会消失得过快。我们给辅助时钟过程中的黑格记分：靠外的格子分值低，某些难处理的边界变化恰好发生在零分位置。严格控制平均失分速度后，再比较更新方式，得到原同步方块经过平方量级轮数仍有固定概率存活，因此平均时间至少达到 cN²。

上界要保证任何图形都能足够快地恢复。我们先用一个边界呈阶梯形的辅助过程包住原图形。阶梯边界能改写成一排粒子：一次有效角点变色，恰好对应粒子与旁边空位交换。

![辅助过程的合法角点更新与一维粒子编码；粒子数保持五个，黑格数可以变化](docs/images/06-particle-encoding.png)

粒子表示边界形状，不是黑格本身。真实时钟下，粒子的平均分布满足扩散方程；不同位置的占据非正相关，让我们能控制粒子数的波动。两者合起来，证明较大的辅助方块中，目标区域在平方时间后有较高概率全白。

![从辅助方块的局部清空概率，经真实时钟与同步比较、重启得到原过程期望上界](docs/images/07-local-clearing.png)

大小方块之间的逐事件比较，先给出原方块在随机时钟下的清空概率。再换算到同步更新，证明原过程每经过一段固定的平方量级轮数，仍未恢复的概率至多再乘一半。把这些尾概率相加，平均恢复时间就至多是 CN²。
