# 随机多数元胞自动机的恢复时间

在二维整数格上，每个格点同步读取上一轮的上、下、左、右四个邻居：下一轮取多数颜色；两黑两白时独立地以各半概率选色。中心格本身不参与投票，不同格点和不同时刻的平票随机选择相互独立。初态是纯色背景上的有限异色扰动。恢复时间 $T$ 是首次回到纯色背景的轮数；如果从未恢复，取 $T=\infty$。

![四邻同步投票规则](docs/images/01-rule.png)

令 $N$ 为包含所有初始异色格的最小平移轴平行方形的边长，以格为单位，**不是异色格的数目**。单个异色格的尺寸为 1，完整 $N\times N$ 方块的尺寸为 $N$。对尺寸恰为 $N$ 的初态，先对随机选择取扩展期望 $\mathbb E[T]$，再对初态取最坏值，记为 $\tau(N)$。黑白互换给出另一种纯色背景；以下结论覆盖两种情形。

已完成的主定理是 $\tau(N)=\Theta(N^2)$。具体地，当 $N\ge 786432000$，

$$
\frac{N^2}{56623104000}\le \tau(N)\le 664066N^2.
$$

上界单独对 $N\ge16$ 成立。下界由实心方块见证，上界覆盖同尺寸的所有初态。下界通过加权面积和零权边界控制辅助过程的漂移，再与原同步过程比较；上界将阶梯边界编码为有限排斥过程，用热衰减和非正协方差控制局部清空，再通过重启得到期望界。后续独立探索将下界改进为 $\tau(N)\ge N^2/576000000$，适用于 $N\ge500001$；它没有改写原封存定理。

主定理源码：[OriginalQuadraticRecovery.lean](formal/analysis/MathResearchAnalysis/OriginalQuadraticRecovery.lean)，其中 `tau_theta_quadratic` 给出渐近结论。常数、定义与审计入口见[结果与验证](docs/RESEARCH_RESULTS.md)。问题背景见 Fatès、Marcovici、Taati 的 [Question 7.4](https://arxiv.org/html/2101.12682v3)。

## 后续研究

[结果与验证](docs/RESEARCH_RESULTS.md)还介绍一个独立的三箱／随机等待网络：其出口曲线等于明确随机等待时间的分布函数。在一组双模型辨识问题中，固定 $a=e=1$、$b=101/100$，比较 $f=1/2$ 与 $f=1$；先以各半概率选一次模型，再由所选模型独立生成 100 次任务。只观察完成时间的任意可测确定性规则，成功率至多约 58.25%；直接观察内部路线标记的一条规则，成功率至少 66%。这些是同一假设下的理论界，不是实验准确率，也不是原自动机恢复时间的新公式。
