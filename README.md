# 随机多数规则：一个黑色小岛需要多久消失？

在一张无限大的方格纸上，每格只有黑、白两种颜色。如果每格不断模仿邻居中的多数，一小片黑色区域会怎样消退？尺寸增大以后，消退时间又会怎样增长？

这个项目尝试证明：**二维同步随机多数规则的最坏平均恢复时间，与初始扰动的尺寸平方同阶。** 我们也在把推导写成 Lean 证明，让计算机逐步核查逻辑。**完整主定理尚未证明完成。**

## 问题与目标

最初，整张方格纸都是白色，只有有限个格点被改成黑色。每过一个时间单位，**所有格点同时更新**，每格只看上、下、左、右四个邻居：

| 四个邻居的颜色 | 该格下一时刻的颜色 |
|---|---|
| 黑色占多数 | 黑色 |
| 白色占多数 | 白色 |
| 两黑两白 | 重新抛一枚公平硬币，决定黑或白 |

每个格点、每次更新使用独立的硬币。中心格原来的颜色不参加投票。这就是这里的 **Maj-Random-If-Equal** 规则。全黑背景上的有限白色扰动，交换两种颜色后得到相同问题。

设初始图形为 x，用 N 表示能包住所有黑格的最小轴平行方形的边长。例如，一个实心 N×N 黑色方块的尺寸就是 N；N 不是黑格总数。

记 Tₓ 为第一次恢复成全白的时间，取初始尺寸恰为 N 的所有图形中，最大的期望恢复时间：

$$
\tau(N)=\max_{x:\,d(x)=N}\mathbb E[T_x].
$$

要证明的目标是：存在不随 N 改变的正常数 c、C，使充分大的 N 满足

$$
cN^2\leq \tau(N)\leq CN^2.
$$

这就是 **τ(N)=Θ(N²)**。上界要控制所有同尺寸的初态；下界只需找到恢复足够慢的初态。它描述的是最坏初态的**平均时间**，并不要求每次随机演化都在固定时刻结束。尚未证明一定恢复时，恢复时间保留为无穷，不能先把困难情形排除。

## 证明路线

直接分析同步更新很难：许多格点一起变化，边界既会收缩，也会在平局时向外鼓出。我们正在建立下面这条路线：

1. **把同步演化拆开。** 利用方格的黑白棋盘结构，将它与两种颜色轮流更新的过程连接起来。
2. **引入随机时钟。** 在辅助过程中，每个格点有一个独立闹钟，平均每单位时间响一次；每响一次，只更新该格。这样更适合逐次分析边界变化。辅助过程与原同步过程之间的时间和概率比较必须另行证明。
3. **证明小岛的收缩速度。** 结合边界几何和随机更新，控制达到明显收缩所需的时间，再建立平方尺度的恢复界。
4. **回到原问题。** 用已经建立的比较和重启工具，得到原同步过程的上下界。

前两步的模型、比较与调度工具已有形式化成果。**第三步的核心概率估计尚未完成，因此整条路线还没有成为完整证明。**

## 目前做到哪里

| 部分 | 已有成果及其作用 |
|---|---|
| 问题定义 | 已精确描述四邻同步更新、独立硬币、原尺寸和最坏期望；恢复时间允许为无穷。 |
| 不同更新方式的比较 | 已证明一批更新顺序、随机时钟和恢复概率的比较工具，为连接原过程与辅助过程做准备。 |
| 边界与面积 | 对用于证明的辅助图形，已建立边界的几何性质，并证明达到特定保护区失守条件后，会出现与尺度平方同阶的缺失面积。 |
| 随机观察时刻 | 已证明按过去信息决定何时观察时，固定格点的剩余等待仍服从指数分布，下一次响铃的随机标记仍是公平硬币；已有与过去历史相关的独立性及联合尾概率结论。 |
| 平方时间界 | **尚未完成。** 还需把局部平均变化累积成真实时间中的收缩估计，并控制辅助过程边界带来的修正项。 |

已有结果通过了 Lean 构建与内核检查，但“已有引理正确”不等于“主定理已经证明”。完整主定理也尚未获得人类专家的独立确认。

## 现在正在做什么

最近的问题是：**如果观察时刻本身取决于之前的随机结果，之后的随机性还能怎样使用？**

例如，我们可以在第一次发现保护区域失守时停下来观察，但不能偷看未来，再挑一个有利时刻。证明中必须严格区分这两种选择。

目前已经核验：对固定格点，在适当的观察时刻之后，它下一次响铃的等待规律和新硬币的公平性仍可与过去分开处理。接下来要把已有的联合尾概率扩展成完整联合分布，再证明：**每次更新的平均面积变化，怎样累积成一段真实时间里的平均面积变化。** 后一条就是这里所需的物理时间补偿公式。

这一步完成后，仍要证明足够强的收缩概率界，才能得到平方时间结论。
