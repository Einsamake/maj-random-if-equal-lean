## 精确模型与已有工程的对应

这里固定自旋编码为论文的负自旋对应 `true`、正自旋对应 `false`。因此全正边界对应现有的固定零边界，初始全负方岛对应 `topConfig`。四个最近邻之外没有中心自旋输入。

现有 `SquareSpin.rule` 的一次独立公平热浴更新在严格多数同号时保持、严格多数反号时翻转、平局时以概率 `1/2` 翻转。每个格点独立 rate-one 时钟，因此有效翻转率是 `0, 1/2, 1`。与 FSS 记号连接时应取 `α = 1/2`；不能取 `α = 1`，也不能因图形构造可能使用两条辅助时钟而擅改物理时间。现有物理时钟总响铃率随格点数增长，而每格速率仍为 1；生成元不能额外除以方形面积。

CMST 居中的格点方形经 `w = z + (L,L)` 变为 `Inside (2*L+1)`。现有有限实现边长是 `n+2`，所以对 `L≥1` 应显式取

```text
N = 2*L + 1,     n = 2*L - 1,     n + 2 = N.
```

中心方岛本身为原点满方岛的平移 `translate (-L,-L) (squareConfig N)`。状态及整个标记场必须同时按已有平移 law 搬运。原始 `distance` 已是可任意平移的最小半开方形边长，不可将它直接记成 `L`。

偶数原尺寸不能由上述等式直接覆盖。若最后采用奇数尺寸的 CMST 输入，仍须分别证明向前／向后相邻奇数方岛的支配关系，以及 `N±1` 的二次常数比较。尺寸 0、1 已有专门恢复结果；它们不需要代入 `2*L-1`。

在现有有限方形中可把辅助区域实现为固定 mask：

```text
clipped_L = { z | |z.1|≤L ∧ |z.2|≤L ∧ |z.1|+|z.2|≤L+1 }.
V_L = { v | abs(embed(v).1 - L) + abs(embed(v).2 - L) ≤ L+1 }.
D_L = { z | 10*(abs z.1 + abs z.2) ≤ 9*L }.
```

其中 `clipped_L`、`D_L` 用居中的整数坐标，`V_L` 用已平移到原点方形的有限顶点坐标；`v∈V_L` 等价于 `embed(v)-(L,L)∈clipped_L`。`V_L` 之外、但仍在外层方形内的格点也必须始终固定为 `false`。直接复用未加 mask 的 `SquareSpin.rule` 并让这些格点自由更新，会得到不同的辅助过程。一个可行实现是在整个有限顶点集上保留现有时钟，mask 外更新定义为恒等，状态保持为零；这需要实际归纳和随机 law 连接。

## 首个建议完整证明：有限严格多数清理

这是确定性有限几何问题，完全不需要概率、停时、轮廓计数或二次尾界假设。已实现 `FiniteMajorityPeeling.lean`，并以 `GridMajorityPeeling.lean` 接真实规则；后续扩展仍待授权。原设计为，先只依赖实际格点四邻和 `Finset`，不要导入最终主定理模块。

对有限负自旋集合 `S : Finset Site`，定义四邻集合 `neighbors4 z`，并定义

```text
degree S z = card (neighbors4 z ∩ S)
prune S    = { z ∈ S | 2 ≤ degree S z }
core S     = iterate prune S.card S
```

这里的清理只删除当前为 `true` 且四邻中 `true` 至多一个的格点。域外自旋为 `false`，所以这正是严格正多数所要求的删除，不将平局也清理掉。

推荐验收的六组结论：

1. **真实四邻计数。** 证明四个方向格点互异，且 `degree S z` 等于现有 `majority4` 四个输入的 `Bool.toNat` 之和；若 `z∈S` 且 `degree S z≤1`，则所有 tie 标记下的实际单点热浴更新都把该点变为 `false`。这样“多数清理”连接实际规则，而不只连接同名抽象函数。
2. **收缩与单调。** `prune S⊆S`；`S⊆T → prune S⊆prune T`。由四邻集合交与有限基数单调直接证明。
3. **有限停止。** `prune (core S)=core S`，并给出不超过 `S.card` 次并行清理的界。证明可用严格包含必降低基数：若所有前面步骤均未稳定，则基数每步至少减一；到 `S.card` 后只能为空，空集已经稳定。不能把存在稳定点作为调用参数。
4. **最大稳定子集。** 若 `R⊆S` 且 `prune R=R`，归纳每次清理得到 `R⊆core S`。这与稳定性及收缩一起表征 `core S`。
5. **清理结果唯一。** 单点合法删除关系 `T = S.erase z`、`z∈S`、`degree S z≤1` 的每个终止有限清理串都结束于 `core S`。证明所有稳定子集在合法删除下保持，终态稳定且包含于原集合，之后用最大性取双包含。只要求合法串实际终止，不把无限不公平调度当成终止串。
6. **幂等与顺序无关。** `core (core S)=core S`；`core` 单调；任何合法删除选择顺序给出同一终态。这使后续改造动力学的 `p` 成为真实定义的函数，而非随选择而变的程序。

该阶段关闭的是“严格多数清理函数是否存在、是否终止、是否有唯一数学含义”的缺口。它不证明一般稳定集合具有简单轮廓；2-core 可能有孔洞或多分量，不能从 `prune S=S` 推出下面的 Good 条件。上述计划预计可作为一个完整窗口内的目标，但需以真实构建结果为准。

### 一个适合并行、且不假设概率结论的小几何任务

在清理模块之外，可先证如下独立的定量楔形格点引理。它是本项目选用的保守常数版本，现已在ClippedDiamondGeometry中实现四个方向：设 `L≥40`，`m = L / 20`，`x` 是 `D_L` 的外邻边界点，则

```text
{ x + (i,j) | 1≤i≤m, 1≤j≤m } ⊆ clipped_L,
```

从而外向东北楔形至少含 `m²` 个点，且可进一步取保守统一下界 `L²/1600`。

具体证明：边界邻点给出 `10*(|x₁|+|x₂|)≤9*L+10`；对上述 `i,j` 用绝对值三角不等式并利用 `20*m≤L`，得到菱形约束。由每一坐标的绝对值界、`i,j≤m` 和 `L≥40`，得到两坐标仍在 `[-L,L]` 内。映射 `(i,j)↦x+(i,j)` 单射，方形计数为 `m²`；自然数除法证明 `L/20≥L/40` 后转实数平方。四个象限由坐标反射得到。

**边界：** 这个计数只给出楔形有足够多格点；“这些点在首个退出时刻之前已经被删去”仍须第 5 行的轮廓几何推导。不能只证楔形基数就报告已有面积损失或二次下尾。
